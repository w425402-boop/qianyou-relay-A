## 1. 你这一棒交付什么

**为什么拆给你**：推荐是独立算法（权重公式），输入只有活动数据和当前用户，输出前 3 名和附近列表；适合单独考算法落地。

逐条交付，不许减项：

1. 实现 `QY.recommendScore(activity, user)`，公式**写死**：`score = 兴趣匹配×40 + 距离分×30 + 热度分×30`。其中 兴趣匹配＝`tags` 与 `interests` 交集数 ÷ `interests` 总数；距离分＝`1 - distance/50`（超 50 按 0 计）；热度分＝`joined/capacity`。
2. **"今日最佳"区**：取推荐分前 3 名展示，区块标题固定为"今日最佳"；按最高得分维度选一句话理由模板：`你关注了{兴趣}` / `离你仅{distance}km` / `已有{joined}人报名`。
3. **"附近"区**：按 `distance` 升序排列，显示距离（"1.2km"格式）。
4. 实现 `QY.topRecommendations(n)` 返回前 n 名，供 check.js 调用。

**交付物**：`js/modules/recommend.js`；`tests/check.js` 里追加 2 条断言（同种子算两次前 3 名不变；抽查一条手算推荐分一致）；《交接单》。

## 2. 契约前置（先看契约再写代码，10 分钟）

对照 CONTRACT.md 第 4 节，本棒 3 个对外函数：

| 函数 | 入参 | 返回值 | 出错行为 |
| :--- | :--- | :--- | :--- |
| `QY.recommendScore(activity, user)` | `activity: Activity`、`user: User` | `number`，0–100 之间的推荐分（不四舍五入到整页展示可以保留 2 位，但返回值不许是字符串） | 参数缺失 → 返回 `0`，不抛 |
| `QY.topRecommendations(n)` | `n: number` | 按分数降序的 `Activity[]`，长度 ≤ n | `n` 缺省 → 3；`n` 超总数 → 返回全部 |
| `QY.renderRecommend()` | 无 | 渲染 `#recommend-slot`（含"今日最佳"与"附近"两块），返回 `undefined` | 容器不存在 → 静默返回 |

**确定性红线**：分数并列时按 `id` 升序作为第二排序键，否则同一份种子算两次顺序会飘，check.js 第一条断言就红。

**只许改（owns）**：`js/modules/recommend.js`
**只许追加（appendOnly）**：`css/style.css`（只追加 M3 区块）、`tests/check.js`（只追加 M3 断言）

红线：**不遵守就是契约违规，扣 3 分/条。**

## 3. 定桩说明（本棒要摘掉的桩）

开局三个函数是 `QY.seam.stub('M3 QY.recommendScore')` 形态，一调用即抛 `[SEAM 未实现]`。

**交付标准**：M3 的 3 个契约函数全部不再是桩，`node tests/contract.js` 的「本棒模块仍是桩」检查转绿。

```js
// js/modules/recommend.js —— 从桩到真实现
(function (root) {
  var QY = (root.QY = root.QY || {});

  var W_INTEREST = 40, W_DISTANCE = 30, W_HOT = 30;   // 权重写死 40/30/30，不许配置化

  // 契约函数：单条推荐分，纯函数，不读 store
  QY.recommendScore = function (act, user) {
    if (!act || !user) return 0;
    var interests = Array.isArray(user.interests) ? user.interests : [];
    var tags = Array.isArray(act.tags) ? act.tags : [];
    var hit = 0;
    for (var i = 0; i < interests.length; i++) if (tags.indexOf(interests[i]) > -1) hit++;
    var sInterest = interests.length ? hit / interests.length : 0;          // 交集÷兴趣总数
    var sDistance = act.distance <= 50 ? (1 - act.distance / 50) : 0;        // 超 50 按 0
    var sHot = act.capacity > 0 ? act.joined / act.capacity : 0;             // 热度
    return sInterest * W_INTEREST + sDistance * W_DISTANCE + sHot * W_HOT;
  };

  // 契约函数：前 n 名；并列按 id 升序保证同种子两次结果完全一致
  QY.topRecommendations = function (n) {
    var state = QY.store.load();
    var me = QY.store.getUser('u01');
    var rows = (state.activities || []).map(function (a) {
      return { act: a, score: QY.recommendScore(a, me) };
    });
    rows.sort(function (x, y) { return y.score - x.score || (x.act.id < y.act.id ? -1 : 1); });
    return rows.slice(0, n == null ? 3 : n).map(function (r) { return r.act; });
  };

  // 渲染：今日最佳 Top3（理由按最高维度选模板）+ 附近按 distance 升序
  QY.renderRecommend = function () { /* 写 #recommend-slot，不改 #activity-list */ };
})(typeof window !== 'undefined' ? window : globalThis);
```

一个坑：`topRecommendations` 返回的必须是**活动对象**，不是 `{act, score}` 包装——M2 的列表渲染与 A7 的联调都按活动对象取字段，包一层下游全崩。
