## 2. 契约前置（先看契约再写代码，10 分钟）

对照 CONTRACT.md 第 4 节，本棒 3 个对外函数：

| 函数 | 入参 | 返回值 | 出错行为 |
| :--- | :--- | :--- | :--- |
| `QY.renderChat(params)` | `Object`（含 `conv`，可缺省） | 渲染会话列表或指定会话，返回 `undefined` | `conv` 指向不存在的会话 → 渲染会话列表并提示，不抛 |
| `QY.openConversation(convId)` | `string` | 该会话对象（`unread` 已清零并落盘） | 会话不存在 → `null` |
| `QY.sendMessage(convId, text)` | `string, string` | 新消息对象 `{ id, convId, fromId, text, time }` | 空/纯空白 `text` → 返回 `null` 且**不写库**；会话不存在 → `null` |

会话 id 规则（契约 1.5）：群聊 `grp_<actId>`，私信 `dm_<userId>`。`sendMessage` 同时要把会话的 `lastMsg` / `lastTime` 更新并落盘，否则会话列表停在旧消息。

**只许改（owns）**：`js/modules/chat.js`
**只许追加（appendOnly）**：`css/style.css`（只追加 M6 区块）、`tests/check.js`（只追加 M6 断言）
**不在你手里**：`js/modules/detail.js`（M4 owns）、`js/router.js`（M1 owns）—— 接线靠**事件委托 + 改 `location.hash`**，一个字节都不许写进那两个文件

红线：**不遵守就是契约违规，扣 3 分/条。**

## 3. 定桩说明（本棒要摘掉的桩）

开局三个函数是 `QY.seam.stub('M6 QY.sendMessage')` 形态，一调用即抛 `[SEAM 未实现]`。

**交付标准**：M6 的 3 个契约函数全部不再是桩，`node tests/contract.js` 的「本棒模块仍是桩」检查转绿。

```js
// js/modules/chat.js —— 从桩到真实现
(function (root) {
  var QY = (root.QY = root.QY || {});
  var ME = 'u01';

  // 契约函数：发消息。空消息直接 null，不写库
  QY.sendMessage = function (convId, text) {
    var t = String(text == null ? '' : text).trim();
    if (!t) return null;                                    // 空消息发不出去
    var state = QY.store.load();
    var conv = null;
    for (var i = 0; i < state.conversations.length; i++) if (state.conversations[i].id === convId) conv = state.conversations[i];
    if (!conv) return null;

    var msg = { id: 'm' + Date.now(), convId: convId, fromId: ME, text: t, time: new Date().toISOString() };
    state.messages.push(msg);
    conv.lastMsg = t;                                       // 会话列表靠这两个字段刷新
    conv.lastTime = msg.time;
    QY.store.save(state);
    QY.renderChat({ conv: convId });                         // 重渲染并滚到底
    return msg;
  };

  // 契约函数：打开会话，未读清零并落盘
  QY.openConversation = function (convId) {
    var state = QY.store.load();
    for (var i = 0; i < state.conversations.length; i++) {
      if (state.conversations[i].id === convId) {
        state.conversations[i].unread = 0;
        QY.store.save(state);
        return state.conversations[i];
      }
    }
    return null;
  };

  // 契约函数：渲染。params.conv 有值就进会话，没有就出会话列表
  QY.renderChat = function (params) { /* 会话列表 / 气泡左右分布 / 输入框 */ };

  // 接线：事件委托，绝不改 detail.js 与 router.js
  document.addEventListener('click', function (e) {
    var el = e.target.closest ? e.target.closest('[data-chat-target]') : null;
    if (!el) return;
    var actId = el.getAttribute('data-activity-id') || '';
    location.hash = el.getAttribute('data-chat-target') === 'dm'
      ? '#/chat?conv=dm_' + el.getAttribute('data-host-id')
      : '#/chat?conv=grp_' + actId;
  });
})(typeof window !== 'undefined' ? window : globalThis);
```

三个坑：①M4 的按钮若没留 `data-chat-target`（A4 交付未到位），用按钮文本"联系发起人""进群聊"兜底匹配，并在交接单写 `INHERITED: M4 按钮无 data 钩子`；②`#/chat?conv=` 的 query 要自己从 `location.hash` 里解析，别指望 M1 的 router 帮你拆；③种子会话要在**首次加载时**写入（`store.load()` 后检查 conversations 为空则补），否则刷新就丢。
